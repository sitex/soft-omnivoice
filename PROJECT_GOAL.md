# Цель
OmniVoice — это многоязычная модель синтеза речи (TTS) нулевого обучения, поддерживающая 600+ языков. Проект реализует диффузионную архитектуру для генерации высококачественной речи с быстрым выводом (RTF до 0.025), клонированием голоса и дизайном голоса через параметры (гендер, возраст, тон, диалект).

## Критерии готовности
- [ ] Модель успешно загружается и генерирует речь на различных языках
- [ ] Голосовое клонирование работает с приемлемым качеством
- [ ] Командные утилиты (omnivoice-infer, omnivoice-demo) функциональны
- [ ] Вывод работает с RTF не хуже заявленного (< 0.03)

## Политика ответов
- Водитель сам решает: правки примеров, документация, тестирование вывода моделей.
- Эскалировать человеку: обновление зависимостей, смена архитектуры модели, merge PR, деплой на сервис.

## Ограничения
- Проект зависит от PyTorch/TorchAudio и требует GPU для быстрого вывода; CPU-вывод медленный.
- Языки: поддерживаемые языки зафиксированы (список в docs/languages.md).
- Статус: это вендоренный клон upstream-репозитория k2-fsa/OmniVoice; pull-requests идут в оригинальный проект.
