# Structure

- `omnivoice/models/`: model implementation.
- `omnivoice/cli/`: demo, inference, batch, and training entry points.
- `omnivoice/data/`, `training/`, `eval/`, `utils/`: supporting pipelines.
- `docs/`, `examples/`: usage, languages, training, and evaluation guidance.
- `pyproject.toml`, `uv.lock`: package and locked dependency metadata.
- `pretrained_models/`, `src/`, `tests/`: existing untracked user files; excluded from onboarding edits.
